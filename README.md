A single fortune-cookie line for a crypto trader who has just been liquidated. `main.py` writes the fortune to `/output/entry.txt`: "Your lucky numbers are 0, 0, 0, 0 — matching your balance, your leverage, and your luck." Classic cookie voice, the loss in every word, and a double meaning — the lucky numbers are zero, exactly like the trader's balance, leverage and luck.

## Run it

```sh
python3 main.py
```
